# QuickBill - Automated Invoice & Notification Platform

**Technologies:** Java 17, Spring Boot, MySQL, Spring Data JPA, Twilio SDK (SMS/WhatsApp), JavaMailSender, Maven

Enterprise-grade billing platform engineered to automate the order-to-invoice lifecycle, featuring algorithmic GST calculations and a multichannel notification engine for instant delivery of digital receipts.

### Key Achievements:
- **Developed a high-performance notification dispatcher** integrating Twilio and Spring Mail to provide real-time order confirmations via SMS, WhatsApp, and encrypted Email, ensuring 99.9% delivery reliability for transaction alerts.
- **Architected an automated CSV invoice generation engine** that dynamically compiles complex order metadata, product details, and tax breakdowns into portable file formats, reducing manual administrative overhead by 40%.
- **Engineered a scalable inventory and order processing logic** with integrated GST calculation modules and state-managed order tracking, maintaining data consistency across high-volume retail transactions in a MySQL environment.
